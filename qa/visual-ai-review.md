# QA — Visual & AI Review

## Purpose

Review visual (foto, video, grafis, AI image/video/voice) supaya akurat, berkualitas, on-brand, dan tidak menyesatkan. Rule: [07 AI Visual & Disclosure](../rules/07-AI-VISUAL-DISCLOSURE-STANDARD.md).

## Required Inputs

- File visual final (resolusi asli).
- Asset sumber (bila edit).
- Kategori visual (A/B/C/D) yang diklaim creator.
- Logo master client.

## Checklist

### Kategori & Kejujuran

- [ ] Kategori visual (A foto asli / B edit ringan / C edit material / D AI) benar.
- [ ] Listing OTA, GBP, website room page, menu → hanya A/B.
- [ ] Tidak ada fasilitas, view, makanan, atau ruang fiktif yang tampil seolah nyata.
- [ ] Sky replacement / object removal tidak mengubah fakta yang diklaim.
- [ ] Porsi & tampilan makanan sesuai yang disajikan.
- [ ] Label AI / "Ilustrasi AI" terpasang untuk C/D.

### Kualitas Teknis

- [ ] Tidak ada artefak AI: jari/tangan aneh, wajah terdistorsi, teks rusak, objek melayang, pola berulang.
- [ ] Resolusi & rasio sesuai platform.
- [ ] Teks on-screen terbaca, tidak tertutup UI platform (safe area).
- [ ] Subtitle akurat.

### Brand

- [ ] Logo dari file master; tidak terdistorsi, tidak di-recolor.
- [ ] Warna/font sesuai brand guide client.

### Orang & Budaya

- [ ] Orang yang dapat dikenali punya consent (cek [privacy-rights-review](./privacy-rights-review.md)).
- [ ] Tidak ada AI image/voice yang meniru orang nyata tanpa consent.
- [ ] Pakaian adat, pura, simbol agama akurat dan ditampilkan hormat.
- [ ] Tidak ada praktik tidak aman (berdiri di tepi tebing, menyentuh satwa, tanpa alat keselamatan).

### Metadata

- [ ] Nama file menyertakan kategori visual.
- [ ] Metadata internal (tool, prompt ringkas, tanggal) tercatat di workspace client.

## Blockers (otomatis Fail)

- Visual AI/edit material dipakai untuk listing/menu.
- Visual menyesatkan tentang fasilitas/view.
- Logo diubah.
- Orang nyata digenerate tanpa consent.
