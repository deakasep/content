## Aturan / Rules

- Hanya link **view/prototype**. Jangan menempel link dengan akses *can edit* di repo.
- Repo ini private, tapi link Figma bisa diteruskan ke orang lain. Atur **Share → Who has access** di Figma (sebaiknya *Only people invited*).
- Jangan memakai data client nyata di file yang link-nya dicatat di sini.
- Setiap link diberi tanggal & versi. Link lama dipindah ke tabel *Riwayat*, tidak dihapus.

## Cara Mengambil Link / How to Get the Link

| Link | Cara |
|---|---|
| File | Buka file → **Share** → *Copy link* |
| Prototype flow tertentu | Mode **Present** → pilih flow di panel kiri → *Share prototype* → *Copy link* (link sudah menyertakan `node-id` frame awal) |
| Frame tertentu (untuk review) | Klik kanan frame → *Copy/Paste as* → *Copy link to selection* |
